## Supplycart UI Deployment Step
	- For every new task, branch out `feature` branch from `master` branch.
	  logseq.order-list-type:: number
	- Perform development on the `feature` branch. Then, commit & push your changes to remote git repo.
	  logseq.order-list-type:: number
	- **IMPORTANT**: Make sure to bump Supplycart UI's package version in `package.json` just like below:
	  logseq.order-list-type:: number
		- logseq.order-list-type:: number
		  ```json
		  {
		      "name": "@supplycart-my/ui",
		      "version": "^3.0.5", // <=== VERSION BUMP HERE
		      "repository": {
		          "type": "git",
		          "url": "git+https://github.com/supplycart/ui.git"
		      },
		      // ...
		  }
		  ```
	- Then, create PR for Supplycart UI. Once merged, Github Workflow will automate the publishing effort for the new package to NPM registry (https://www.npmjs.com/package/@supplycart-my/ui)
	  logseq.order-list-type:: number
	- Once you have confirmed that the new package has been published, make sure to install them to Adam before you create a PR for Adam:
	  logseq.order-list-type:: number
		- Update the package version in Adam's `package.json` just like the below example:
